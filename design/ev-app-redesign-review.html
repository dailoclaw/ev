Part I · Step 1 — Current UI Analysis

Where the product stands today

The current build is a competent, mobile-first dark dashboard — but it is structurally a one-and-a-half page app: Overview, History, one bottom sheet. The audit covers both the visual layer and the product layer.

✅ Strengths

  • Clean single-column mobile layout with a clear visual spine
  • Strong typographic hierarchy — big hero number, confident weights
  • Sensible provider color-coding across all four charger types
  • Thoughtful details: safe-area insets, fixed tab bar, bottom-sheet modal, empty states
  • Consistent radius system & reusable metric cards

⚠️ Weaknesses

  • Dark-only — no light mode; dim and dated for a data tool
  • Low-opacity white-on-navy surfaces = muddy contrast
  • Only 2 pages — no add-data flow, no insights hub, no settings, no per-charger pages
  • Letter-glyph provider marks (J/M/C/S) read as placeholder
  • Hard-coded charger types — adding a provider requires a code change
  • No micro-interactions beyond a 1px hover lift
  • Data is trapped in a bundled JSON — no sync, no export

Data Requirement — Supabase Integration v2

Live data: migrate, add & sync, export — and new charger types

All 249 sessions currently live in a bundled ev_data.json. The plan below meets all four requirements — including the new one: charger types must be dynamic, so a new provider can be added in-app without a code change.

Requirement 1

Migrate JSON → Supabase

One-time seed script inserts providers first, then the 249 sessions with FK links. Postgres becomes the source of truth.

Requirement 2

Add data + live sync

"Add session" sheet writes via supabase-js; optimistic insert + realtime channel keeps every device in step.

Requirement 3

Export to CSV

One tap exports the full or filtered ledger (with provider names joined) to an Excel-ready CSV, generated client-side.

Requirement 4 · NEW

Dynamic charger types

A providers table replaces the hard-coded list. "+ New" in the add flow creates a provider with an auto-assigned colour; chips, filters and charts pick it up instantly.

Colour auto-assignment

New providers pull the next unused hue from a curated 10-colour palette (teal → indigo → violet → rose → amber → cyan → lime → fuchsia → sky → orange), so charts and chips stay distinct without user effort — with an optional colour picker in Manage chargers.
