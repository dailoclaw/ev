Supabase v3 — now powering the savings math

Migrate · add & sync · CSV · dynamic chargers · free allowances

Same four requirements as before, plus the providers table gains a free_kwh_per_day column — so the free-energy feature is data, not code. Add a new charger with its own daily free allowance and every savings figure updates automatically.

Schema

providers

iduuid pk
nametext unique
colortext · auto-assigned
free_kwh_per_daynumeric · Jolt = 7, default 0
Schema

charging_sessions

iduuid pk
provider_iduuid → providers.id
date / amount / costdate · numeric kWh · numeric AUD
notestext nullable
Derived

daily_free_energy (view)

Per provider per day: least(free_kwh_per_day, sum(amount)). The app multiplies by your measured paid rate to price the saving. No client-side hard-coding of "7".

-- providers seed (free allowance is data, not code)
insert into providers (name,color,free_kwh_per_day) values
 ('Jolt','#0d9488',7),('Matty','#6366f1',0),
 ('Chargefox','#8b5cf6',0),('Supercharger','#f43f5e',0);

-- savings view
create view daily_free_energy as
select s.provider_id, s.date,
  least(p.free_kwh_per_day, sum(s.amount)) as free_kwh
from charging_sessions s join providers p on p.id=s.provider_id
where p.free_kwh_per_day > 0
group by s.provider_id, s.date, p.free_kwh_per_day;
// app: chips + allowances rendered from the table
const { data: providers } =
  await db.from('providers').select('*').order('name')

// new charger WITH its own free allowance
await db.from('providers').insert(
  { name:'Evie', color: nextColor(), free_kwh_per_day: 0 })

// CSV export — provider name + free flag joined
const { data } = await db.from('charging_sessions')
  .select('date,amount,cost,notes,providers(name)').csv()
downloadBlob(data,'ev-charging-export.csv')
